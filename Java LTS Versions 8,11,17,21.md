# Java LTS Versions 8,11,17,21

### **📌 Java LTS Versions and Enhancements**

| **Java Version** | **Release Year** | **Key Enhancements** |
| --- | --- | --- |
| **Java 8 (LTS)** | 2014 | 🔹 **Lambdas & Functional Interfaces**🔹 **Stream API**🔹 **Default & Static Methods in Interfaces**🔹 **Optional Class**🔹 **New Date-Time API (`java.time`)**🔹 **Parallel Sorting (`Arrays.parallelSort()`)** |
| **Java 11 (LTS)** | 2018 | 🔹 **String Methods (`strip()`, `isBlank()`, `repeat()`)**🔹 **New `HttpClient` (Standardized)**🔹 **Z Garbage Collector (ZGC)**🔹 **Single-File Source Execution (`java MyFile.java`)**🔹 **Removed Java EE & CORBA Modules** |
| **Java 17 (LTS)** | 2021 | 🔹 **Sealed Classes (Standardized)**🔹 **Pattern Matching for `instanceof` (Standardized)**🔹 **Deprecation of Security Manager**🔹 **New `RandomGenerator` API**🔹 **macOS Metal Rendering Pipeline** |
| **Java 21 (LTS)** | 2023 | 🔹 **Virtual Threads (Standardized - Project Loom)**🔹 **String Templates (Preview - `STR."Hello, {name}!"`)**🔹 **Pattern Matching in Switch (Standardized)**🔹 **Sequenced Collections (`List`, `Set`, `Map`)**🔹 **Scoped Values (Preview - Alternative to `ThreadLocal`)** |
